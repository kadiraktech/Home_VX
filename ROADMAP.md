# Roadmap

## Phase 1: Current Scope

- Keep the project lightweight and reproducible.
- Profile the existing `ev.csv` dataset.
- Generate real charts and written insights from the data.
- Train a simple baseline regression model.
- Document limitations clearly.

## Phase 2: Better Analysis

- Add more robust outlier review.
- Compare baseline linear regression with a tree-based model.
- Add cross-validation if the dataset grows.
- Improve feature engineering for room count and heating categories.
- Add a reproducible HTML report with R Markdown or Quarto.

## Phase 3: Presentation

- Add real generated charts to the README after script execution.
- Add a short project walkthrough section for CV/portfolio visitors.
- Add CI that checks the R scripts can run.

## Out Of Scope For Now

- Shiny dashboard
- Docker setup
- Backend API
- Frontend application
- Production valuation service
